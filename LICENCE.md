## 🧩 About

**The First Berserker Khazan Companion** is a curated list of The First Berserker Khazan open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, checkpoint switcher
- **Quality-of-Life Helpers** — item catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- Checkpoint Switcher — practice from any checkpoint
- Show Hitboxes — visualize enemy and attack hitboxes
- Replay Notes — record and review combat runs
- Playback Speed — adjust combat playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse weapons, armor, and accessories
- Custom Skin Notes — organize character cosmetics
- Enhanced Visibility — improved visual cues for study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Camera Control — manually adjust camera angle mid-fight
- Combo Buffer Notes — chain complex maneuvers in practice
